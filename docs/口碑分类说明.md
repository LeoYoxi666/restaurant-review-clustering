# 口碑分类说明

## 使用说明

分类综合总体评分、环境、口味、服务、评分波动、评论情感和主题信号。标签反映数据中的相对口碑结构，不是绝对质量认证。

有效评价少于 3 条的商家标记为 `样本不足`；无关联评价的商家标记为 `暂无有效评价`。

## 标签定义

### 全面高口碑型

- 商家数：24,341，占可聚类商家的 18.5%。
- 评分特征：总体 3.86，口味 3.30，环境 3.26，服务 3.18。
- 分类原因：总体平滑评分较均值高 0.30 分，口味、环境和服务均处于四类最高水平；环境和服务主题评论占比分别为 34.3% 和 32.7%。
- 类别区别：该类不是单一维度突出，而是总体及三个细分评分同步领先。
- 经营建议：保持综合体验，并重点控制评分波动，排查门店、时段或人员造成的不一致。

### 口味优势型

- 商家数：30,758，占可聚类商家的 23.4%。
- 评分特征：总体 3.64，口味 3.18，环境 2.41，服务 2.56。
- 分类原因：口味评分为 3.18，分别高于环境和服务 0.77、0.61 分；75.1% 的有评论评价提及口味相关词，是四类中最高。
- 类别区别：口味形成清晰主优势，但环境和服务没有同步达到同等水平。
- 经营建议：保持核心菜品稳定，把环境和服务作为优先补齐项。

### 均衡稳定型

- 商家数：48,049，占可聚类商家的 36.5%。
- 评分特征：总体 3.57，口味 2.90，环境 2.78，服务 2.73。
- 分类原因：总体平滑评分与均值仅相差 0.01 分，三个细分评分最大差距为 0.17 分；评分波动较均值低 0.08。
- 类别区别：没有单项形成压倒性优势或明显短板，评价结构更接近整体中位状态。
- 经营建议：维持现有稳定性，优先从服务细节和复购体验寻找增量。

### 整体改善型

- 商家数：28,548，占可聚类商家的 21.7%。
- 评分特征：总体 3.21，口味 2.62，环境 2.44，服务 2.40。
- 分类原因：总体平滑评分较均值低 0.35 分，口味、环境和服务均偏低；负面词评价占比 54.3%，情感净值较均值低 11.4%。
- 类别区别：与单项短板类别不同，该类的低分分布在多个体验维度。
- 经营建议：先处理服务维度及卫生、等待等高频问题，再跟踪整改后的差评率。

### 样本不足

已有评价但少于 3 条。信息不足以稳定判断口碑结构，保留为独立标签，等待后续数据积累。

### 暂无有效评价

商家主表中存在，但评价表中没有可关联记录。该标签表示缺少证据，不代表好评或差评。
